Rhythm Blind Trainer — это веб-приложение для развития чувства ритма, музыкального слуха и координации. Главная особенность — слепой режим, который отключает звук метронома после заданного количества тактов, заставляя вас удерживать ритм по памяти.

Приложение работает полностью в браузере, без установки, оптимизировано для мобильных устройств и поддерживает офлайн-режим.

✨ Возможности
Функция	Описание

🎯 4 уровня сложности	Лёгкая (120мс) → Профи (30мс) — разные допуски для точности

🔇 Слепой режим	Метроном играет N тактов, затем замолкает — держите ритм сами

🥁 5 звуков ударных	Kick, Snare, Hi-Hat, Clap, Cowbell — выбирайте на свой вкус

📊 Статистика в реальном времени	Точность удара (%), отклонение (мс), комбо-серии

📈 Сохраняемые рекорды	Лучшая комбо сохраняется в localStorage

🎨 Визуальный осциллограф	Живая анимация звуковой волны

📱 Мобильная оптимизация	Адаптивный дизайн, жесты, виброотклик

💾 Offline-first	Service Worker для работы без интернета

🎮 Как играть

Выберите ритм — 2, 4, 6, 8 или 10 тактов

Выберите сложность — от Лёгкой до Профи

Нажмите СТАРТ — начнётся тренировка

Попадайте в такт — нажимайте на барабан или клавишу Пробел

Слепой режим — попробуйте удержать ритм после отключения звука

🎯 Допуски по сложности
Сложность	🎯 Идеально	👍 Хорошо	⚡ Попал

🟢 Лёгкая	< 120 мс	< 180 мс	< 250 мс

🟡 Средняя	< 80 мс	< 140 мс	< 220 мс

🔴 Сложная	< 50 мс	< 100 мс	< 180 мс

⚫ Профи	< 30 мс	< 70 мс	< 150 мс

🚀 Установка и запуск
